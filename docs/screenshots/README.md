# Screenshots

`analyze.svg`, `convert.svg`, and `tag.svg` are **placeholder mockups** used by the
main README so it renders cleanly before real captures exist.

To replace them with real screenshots:

1. Capture each tool (macOS: `Cmd`+`Shift`+`4`, then space to grab the window).
2. Save them as `analyze.png`, `convert.png`, `tag.png` in this folder.
3. In the root `README.md`, change the three `docs/screenshots/*.svg` paths to `*.png`.

Aim for a consistent window size and a representative (non-empty) library.
