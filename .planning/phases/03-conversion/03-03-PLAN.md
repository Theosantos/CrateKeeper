Layer CONV-05 (resume-after-interruption) on top of the Plan 03-01 controller + Plan 03-02 UI. Add a heartbeat-based crash-detection sweep at main boot (before any window opens, per Pitfall 9); fill in the conversion:list-resumable + conversion:resume IPC handlers (stubs in Plan 03-01) by delegating to the existing repo.findResumable() + a new controller.resume() implementation; surface a Reprendre / Ignorer banner in ConvertirView that fires on mount via useConversionStore.checkResumable(). Purpose: This closes the last open requirement in Phase 3 (CONV-05). All persistence infrastructure already exists in Plan 03-01's conversionRepo (heartbeat_at column, findResumable, markStaleAsCrashed, getResumablePending, deleteConversion). This plan wires those primitives into a user-visible flow without changing the schema or the worker.

Output: A user who's mid-conversion when the app crashes (or force-quits) will see, on next launch, a banner `Reprendre la conversion de N fichiers ?` above the Convertir preset selector. </objective>

    ```ts
    async resume(conversionId: string): Promise<void> {
      if (activeConversion) {
        throw new BatchAlreadyActive('Une conversion est déjà en cours')
      }
      const row = deps.repo.getConversion(conversionId)
      if (!row || row.status !== 'crashed') {
        throw new Error('Batch not resumable')
      }
      const pending = deps.repo.getResumablePending(conversionId)
      if (pending.length === 0) {
        // No work left — flip status to 'done' and emit done.
        deps.repo.complete(conversionId, { status: 'done', endedAt: deps.now() })
        deps.send(IpcChannels.ConversionEvent, { type: 'done', conversionId })
        return
      }
      const preset: Preset = JSON.parse(row.preset_json)
      const ffmpegPath = deps.resolveFfmpegPath({ rawPath: deps.getFfmpegRawPath(), isPackaged: deps.isPackaged })
      const parallelism = Math.max(1, Math.min((deps.cpuCount?.() ?? os.cpus().length) - 1, 4))
      deps.repo.updateConversionStatus(conversionId, 'running')   // resurrect the row
      deps.repo.bumpHeartbeat(conversionId, deps.now())
      const worker = deps.spawnWorker({ conversionId, files: pending, ffmpegPath, preset, outputDir: row.output_dir, parallelism })
      // ...same heartbeat timer setup + attachWorker as start()
    }
    ```
