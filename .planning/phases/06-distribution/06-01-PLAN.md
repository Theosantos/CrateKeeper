<objective>
Slice A (macOS): produce a working, installable macOS Universal `.dmg` for CrateKeeper 1.0.0 with FFmpeg bundled and resolving at runtime. This is the earliest slice and owns the shared cross-cutting config (`electron-builder.yml`, the `package.json` version bump) that the Windows and release slices extend.

Delivers DIST-01 (single-file `.dmg` installer, no prior install) and DIST-02 (FFmpeg bundled, no system dependency) on macOS.

Purpose: A non-developer DJ on a Mac (Apple Silicon OR Intel) can download one `.dmg`, drag the app to Applications, right-click → Open, and run a conversion — with zero Homebrew/Node/FFmpeg setup.
Output: `electron-builder.yml`, `scripts/prepare-universal-ffmpeg.sh`, an updated `package.json` (version 1.0.0 + universal `build:mac` script), and a built `dist/CrateKeeper-1.0.0-universal.dmg` verified via build-time assertions and a human-verify smoke test.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | Unsigned `.dmg` (binary replacement / Gatekeeper "damaged") | accept | Accepted v1 risk per D-01; mitigation path = code signing + notarisation in v2 (`build/entitlements.mac.plist` already present, D-03). Users only right-click→Open apps downloaded from the official Releases page (D-02). |
| T-06-02 | Tampering | `prepare-universal-ffmpeg.sh` downloads from ffmpeg-static GitHub release | mitigate | Download over HTTPS (`curl -fL`) from the pinned release tag `b6.1.1` only; `-f` fails the build on HTTP error so a swapped/404 binary cannot silently ship. Binaries originate from the same vendored ffmpeg-static@5.3.0 already in production use. |
| T-06-SC | Tampering | npm installs in this plan | mitigate | This plan adds NO new npm packages — electron-builder, ffmpeg-static, better-sqlite3 are already installed and in production. No `[ASSUMED]`/`[SUS]` package introduced here (electron-updater is gated in 06-02). |
