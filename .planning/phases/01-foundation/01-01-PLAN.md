<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer → preload → main | Renderer (Chromium, untrusted-by-design) crosses contextBridge into preload, then ipcRenderer.invoke into the Node main process. All Node/filesystem/DB access happens only on the main side. |
| main → filesystem (userData + selected folder) | Main process reads/writes the SQLite DB at userData and persists a user-selected folder path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-01 | Elevation of Privilege | BrowserWindow (src/main/index.ts) | mitigate | Set contextIsolation:true, nodeIntegration:false, sandbox:true explicitly (Task 3); load only the local bundle, no remote URLs. |
| T-1-02 | Tampering | settings:set-folder handler (src/main/ipc/settings.ts) | mitigate | Type-check the incoming path is a string before persisting; the value originates from OS-validated showOpenDialog. No path concatenation into SQL. |
| T-1-03 | Tampering | SettingsRepo SQL (src/main/db/settingsRepo.ts) | mitigate | Parameterized prepared statements only; no string-interpolated SQL (RESEARCH Security V5). |
| T-1-SC | Tampering | npm installs (scaffold + deps) | mitigate | RESEARCH Package Legitimacy Audit ran slopcheck 0.6.1 on all 15 packages → 15/15 [OK], no [SUS]/[SLOP]. better-sqlite3 postinstall is the expected prebuild-install flow, not exfil. |
</threat_model>
