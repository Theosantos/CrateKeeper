library is clean and tagged without leaving the app or risking corruption.

surface) complete the end-to-end loop.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-TMP | Tampering | tagWriter temp file naming | mitigate | Deterministic per-file temp name `<file>.ck-tmp` in `path.dirname(filePath)`; the batch (Plan 02) is sequential so two writes never target the same temp concurrently |
| T-05-FF | Tampering | ffmpeg binary path for MP4 remux | mitigate | `ffmpegBinaryPath` is injected from `resolveFfmpegPath()` (bundled ffmpeg-static), never from user/DB input — no injection vector |
| T-05-CORRUPT | Denial (data loss) | in-place MP3 write | mitigate | Atomic temp-copy + `NodeID3.update` on the copy + `fs.rename`; on any throw `fs.rm(tmp)` leaves the original byte-identical (TAGS-02) |
| T-05-DESTRUCT | Tampering | NodeID3 frame merge | mitigate | Use `update()` not `write()`, and never put null keys in the tags object — existing untouched frames are preserved (D-04) |
| T-05-SC | Tampering | npm install node-id3 | mitigate | Task 0 blocking-human legitimacy checkpoint before install ([ASSUMED] package); no postinstall script confirmed |

No high-severity unmitigated threats remain.
</threat_model>
